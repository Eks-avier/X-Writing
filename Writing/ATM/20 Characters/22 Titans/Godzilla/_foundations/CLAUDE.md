# CLAUDE.md - Species Foundations

## Overview

This folder contains **species-level documentation** for *Titanus gojira* traits that apply universally to the species, not just to Godric specifically. Content here is referenced by individual character profiles (Godric, Dagon, future Astraea profile) rather than duplicated.

## Scope Distinction

| Location | Scope | Examples |
|----------|-------|----------|
| `Godzilla/Identity/` | Godric-specific | His standing, his titles, his name choices |
| `Godzilla/_foundations/` | Species-wide | Limitless Adaptation, Krátos mastery, Ascendant classification |
| `30 Lore/33 Species/Titanus Gojira/` | Encyclopedic | Full species documentation with history, culture, biology |

## File Inventory

| File | Content | Applies To |
|------|---------|------------|
| `species-traits.md` | Core gojiran traits (Limitless Adaptation, Krátos, Ascendant status) | All *Titanus gojira* |

## Usage

When documenting a *Titanus gojira* character:
1. **Species traits** → Link to `_foundations/species-traits.md`
2. **Individual identity** → Keep in character's `Identity/` folder
3. **Full species lore** → Link to `30 Lore/33 Species/Titanus Gojira/`

## Maintenance

When adding species-wide information:
- If it applies to ALL gojira → Add to `_foundations/`
- If it applies only to Godric → Add to appropriate `Godzilla/` subfolder
- If it's encyclopedic detail → Add to `30 Lore/33 Species/`
