## Symbolic Notation System

### Ariston Manifestations (Fundamental Forces)

| Symbol | Term | Description |
|--------|------|-------------|
| Nr | Pyrenikon | Nuclear phenomena (atomic energy) |
| Em | Elektromagneton | Electromagnetic phenomena |
| By | Baryton | Gravitational phenomena |
| Ps | Psioniton | Psiforce manifestation |
| Pm | Primoton | Primus manifestation (theoretical) |

**Em Specialized Variants:**
- Electron
- Magneton
- Photon

### Kakiston Manifestations (Classical Elements)

| Symbol | Term | Description |
|--------|------|-------------|
| Py | Pyroton | Fire/heat phenomena |
| Hy | Hydroton | Water phenomena |
| Ky | Kryoton | Ice/cold specialization |
| Ae | Aeroton | Air/wind phenomena |
| Ge | Geoton | Earth/stone phenomena |

**Combined Forms:**
- Thermoton = Pyroton + Kryoton (unified temperature control)

## Classification Framework

### Count Classifications

| Term | Meaning |
|------|---------|
| MONOKRÁTON | Single phenomenon manifestation |
| POLYKRÁTON | Multiple phenomena manifestation |

### Class Classifications

| Term | Meaning |
|------|---------|
| ARISTON KRÁTON (ἄριστον κράτων) | Fundamental force access |
| KAKISTON KRÁTON (κάκιστον κράτων) | Classical element access |

### Scope Classifications

**For Aristons (Fundamental Force Users):**

| Term | Meaning |
|------|---------|
| HOLARISTON (ὁλάριστον) | Complete fundamental force control |
| IDIARISTON (ἰδιάριστον) | Specialized fundamental force subset |

**For Kakistons (Elemental Users):**

| Term | Meaning |
|------|---------|
| EURYKAKISTON (εὐρυκάκιστον) | Multiple/broad classical elements |
| STENOKAKISTON (στενοκάκιστον) | Single/narrow classical element |

## Special Designations

### Nomothete

**Meaning:** "Lawgiver" - A Krátor who has achieved such mastery that their techniques become the standard by which others are measured.

**Known Nomothetes:**
- Godzilla (Kratos exemplar)
- Ghidorah (Kratos exemplar)

### Hybrid Practitioners

When a being has both Kratonic manifestation AND another system:

| Character | Kratos | Other System |

| Scylla | Stenokakiston (Ky) | Hydrokinesis (Psionics) |
| Junior/Leo | Holariston (Nr+Em) | Telekinesis (Psionics) |
| Biollante | Holariston (Nr) | Plant Psychokinesis |

## The Genetic Lock Principle Applied

Every aspect of classification is **permanently determined at birth**:

| Locked Aspect | Cannot Change |
|---------------|---------------|
| Manifestation Count | Single ↔ Multiple |
| Manifestation Class | Fundamental ↔ Elemental |
| Manifestation Scope | Narrow ↔ Broad |
| Specific Phenomena | Add or remove |
| Practitioner Type | Koinon ↔ Krator |

**Training can improve:** Efficiency, control, techniques, applications
**Training cannot change:** Core classification
