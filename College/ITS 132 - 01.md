## What is Data Mining?

- The process of discovering interesting **patterns**, **models**, and **other kinds** of knowledge in *large* data sets.

> [!IMPORTANT] “Knowledge mining from data”

- Other terms may be:
	- **KDD**: **K**nowledge **D**iscovery from **D**ata
	- Pattern Discovery
	- Knowledge Extraction
	- Data Analytics
	- Information Harvesting
- It is a *young* and *promising* field

## I. Diversity of Data Types for Data Mining

The real-world data can often be a **mixture** of structured, semi-structured data and unstructured data.

### A. Structured Vs Unstructured Data

#### 1. Structured

- Uniform
- Record- or table-like structures
- Defined by data dictionaries
- Possesses a fixed set of attributes, each with a fixed set of value ranges and semantic meaning

> [!EXAMPLE] Structured Data Examples
> - Data stored in relational databases
> - Data cubes
> - Data matrices
> - Most data warehouses

#### 2. Semi-structured Data

- Allows a data object to contain a:
	- **set value**
	- **small set of heterogenous typed values**
	- **nested structures**
- Allow the structure of objects or sub-objects to be defined **flexibly** and **dynamically**
- Data having certain structures with *clearly* defined semantic meaning.

> [!EXAMPLE] Semi-structured Data Examples
> - Transactional data set
> - Sequence data set
> 	- time-series data
> 	- gene
> 	- protein data
> 	- Weblog data

#### 3. Unstructured Data

- Text and multimedia, e.g., audio, image, video data

### B. Data Associated with Different Applications

- Different applications provide different data sets and require different data analysis methods
	- **Sequence data**: biological sequences vs. shopping transaction sequences
